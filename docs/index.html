ESP32-S3 OBD2 Dashboard for ELM327 Bluetooth & WiFi adapters

Open-source firmware that turns the Waveshare ESP32-S3-Touch-LCD-2.1 round touch display into a digital gauge cluster for any OBD-II car: RPM, speed, coolant and oil temperature, battery voltage, live sensor data and a trouble-code (DTC) reader.

Source on GitHub Download firmware

Features

BLE or WiFi ELM327

Works with cheap ELM327 clones over Bluetooth Low Energy (FFF0/FFE0) or WiFi (TCP 192.168.0.10:35000). Switch in Settings, no reboot.

Universal OBD-II

Automatic protocol detection with a cached protocol for instant reconnects. CAN, K-line KWP2000, ISO 9141-2, J1850.

Smooth gauges

Synchronized RPM and speed at ~60 FPS, shift lights, redline zone, EMA filtering on every sensor.

Trouble codes

Read stored and pending DTCs, freeze-frame data and MIL status; clear codes with verification; history kept in flash.

Only supported data

PIDs are discovered at connect time; the UI shows what your car actually reports, including oil temperature and fuel level.

Built for a round screen

Every screen is designed for the 480×480 circular panel: rings, a central lens and swipe navigation. Plus an off-road inclinometer.

Quick start

git clone https://github.com/erdemerciyas/ESP32-S3-OBD2.git
cd ESP32-S3-OBD2
idf.py build                 # ESP-IDF v5.3.5
idf.py -p COM3 flash monitor

Or flash the prebuilt image from the latest release:

esptool.py --chip esp32s3 -p COM3 write_flash 0x0 esp32s3-obd2-dashboard-merged.bin

Türkçe
